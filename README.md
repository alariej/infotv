# InfoTV

Starter web app for a TV browser using Vite + React + `react-native-web`.

## Getting started

```bash
npm install
npm run dev
```

By default, the dev server binds to all interfaces (`--host`) so you can open it from another device on your network.

## Project notes

- Vite config aliases `react-native` imports to `react-native-web`.
- The starter screen in `src/App.jsx` includes placeholder panels for weather and news.
